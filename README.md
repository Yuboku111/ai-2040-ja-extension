# AI 2040 Visual Novel 日本語化

[ai-2040.fun](https://ai-2040.fun/) のシナリオと操作画面を日本語化する、
Chrome向けManifest V3拡張機能です。

> [!IMPORTANT]
> 非公式のファンプロジェクトです。AI Futures Project、ai-2040.com、
> ai-2040.fun、および原作者・翻案者による承認や提携を示すものではありません。

## 機能

- 全チャプター、全分岐、ボーナス視点を含むシナリオを日本語化
- タイトル、設定、操作説明、履歴、チャプター、ダッシュボードを日本語化
- 元サイトの画像・音楽・ゲームエンジン・セーブデータをそのまま使用
- 権限、バックグラウンド処理、アクセス解析、外部通信を追加しない

翻訳は機械翻訳を土台にした初版です。不自然な表現や文脈上の誤りは、Issueまたは
Pull Requestでぜひ改善してください。

## インストール（開発者モード）

1. このリポジトリをダウンロードまたはクローンする
2. Chromeで `chrome://extensions` を開く
3. 右上の「デベロッパー モード」を有効にする
4. 「パッケージ化されていない拡張機能を読み込む」を選ぶ
5. このリポジトリのルート（`manifest.json` があるフォルダ）を指定する
6. [ai-2040.fun](https://ai-2040.fun/) を開く、または再読み込みする

更新時は `chrome://extensions` でこの拡張機能の更新ボタンを押し、サイトを再読み込みしてください。

## 仕組み

拡張機能はページ読み込み開始時に、ゲームエンジンが取得する `script.md` だけを
同梱済みの日本語シナリオへ差し替えます。UIの動的な文言はMutationObserverで
監視し、日本語ラベルに置換します。元サイトのサーバーや保存領域には変更を加えません。

```text
manifest.json
├── data/script-ja.js       # 日本語シナリオ
└── content/
    ├── main.js             # fetch差し替え・UI翻訳
    └── japanese.css        # 日本語向けフォントと組版
```

## 開発・検証

依存パッケージやビルド工程はありません。

```sh
python3 -m json.tool manifest.json >/dev/null
node --check data/script-ja.js
node --check content/main.js
```

動作確認では、少なくとも次を確認してください。

- 初回起動後、本文と話者名が日本語で表示される
- 2029年の5分岐すべてを選択できる
- 設定、履歴、チャプター、クレジットを開閉できる
- 再読み込み後も「続きから」で再開できる
- DevTools Consoleに `[AI 2040 JA]` のエラーがない

## コントリビューション

翻訳修正は `data/script-ja.js` の長い1行を直接編集せず、Issueで「英語原文・現在の訳・
提案訳・登場箇所」を提示してください。メンテナーは生成元の翻訳データへ反映してから
ファイルを再生成します。詳細は [CONTRIBUTING.md](CONTRIBUTING.md) を参照してください。
